# 🍷 Винна карта (WineCard)

## Опис проєкту

**Винна карта** — це Android-застосунок для перегляду каталогу вин, ознайомлення з їхніми характеристиками та створення власної колекції улюблених вин.

Застосунок розробляється в межах лабораторних робіт протягом семестру.

## Основні екрани

1. **Каталог вин** — перегляд списку вин із зображеннями та сортуванням за рейтингом.
2. **Деталі вина** — інформація про вибране вино, його регіон, рейтинг і зображення.
3. **Мій погріб** — список улюблених вин, збережених на пристрої.
4. **Налаштування** — налаштування застосунку.

## Технології

- Kotlin
- Android Studio
- Jetpack Compose
- REST API
- Git та GitHub

## Джерело даних

Використовується безкоштовний публічний API SampleAPIs, який не потребує API-ключа або авторизації.

API: https://api.sampleapis.com/wines/reds

## Локальне збереження

У застосунку передбачено збереження улюблених вин на пристрої користувача.

## Основні можливості

- Перегляд каталогу вин.
- Перегляд інформації про вино.
- Сортування вин за рейтингом.
- Додавання вин до обраного.
- Перегляд власної колекції.

## Статус проєкту

Проєкт перебуває на початковому етапі розробки. Реалізація функцій відбуватиметься поступово в межах лабораторних робіт.

## Лабораторна робота №1

**Тема:** Ідея застосунку на екрані.

**Мета:** визначити концепцію застосунку, його основні екрани, джерело даних і створити початковий інформаційний екран в Android Studio.
