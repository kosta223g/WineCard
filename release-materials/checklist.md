# Перевірка release 1.0.0

Статус: чекліст для виконання на реальному пристрої або емуляторі. Не є звітом про пройдені тести.

- [ ] Чистий запуск підписаного release APK із лаунчера при закритій Android Studio.
- [ ] Назва «Винна карта» і власна іконка на світлому та темному фоні.
- [ ] Каталог: усі категорії, фото, сортування, прокручування, жест оновлення.
- [ ] Пошук: перша літера, підказки, відсутність збігів, очищення.
- [ ] Деталі: повернення до того самого місця списку, додавання та зняття сердечка.
- [ ] Погріб: порожня добірка, вина різних категорій, видалення, перезапуск.
- [ ] Налаштування: три теми, сортування, відмова в дозволі сповіщень.
- [ ] Поворот пристрою на каталозі, деталях, погребі та налаштуваннях.
- [ ] Авіарежим із вимкненим Wi-Fi: холодний запуск, помилка, повтор після підключення.
- [ ] Авіарежим після завантаження каталогу: свайп оновлення, старі дані залишаються.
- [ ] Перевірка відступів, читабельності та фото у двох темах.
- [ ] Підписаний APK і AAB, mapping.txt збережено приватно, ключ не в Git.
- [ ] Знято 5 реальних скріншотів: каталог, деталі, пошук, погріб, темна тема.
